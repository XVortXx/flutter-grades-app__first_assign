## ✨ Features

- **⚡ Real-Time Average Calculation:** Dynamic class average updates instantly as student scores change.
- **🔄 Interactive Score Controls:** Intuitive `+` and `-` buttons to adjust scores (bounded between `0` and `100`).
- **🎯 Dynamic Status Indicators:**
  - 🟢 **Green Check:** Passing grade ($\ge 56$)
  - 🔴 **Red Cross:** Failing grade ($< 56$)
- **🌐 Full RTL Support:** Native Right-to-Left layout optimized for Hebrew typography and UI ergonomics.
- **🎨 Material 3 Design:** Minimalist, clean pastel color palette and rounded component styling.
